# Soulblade Lab 41 integration

Source: Soulblade Lab commit 2f1a2aa693e7a42e5db827f4e64e3fc6695b3497 (Lab 3.22), based on Saga Fight d5da1b9b02a913a18bea62694600c8350fe740ee. Imported the approved contour/weapon, deterministic motion rig, normal sequence and W handoff, E reveal/mist/sparkles, R glow and bleed effects. Q preserves the restored Lab 3.20 renderer exactly, as approved for integration; no further Q redesign was made.

Lab playback/freeze/configuration hooks and automatic sandbox shell were removed. Q remains a single 3-second cooldown cast, with the main game's damage/range/timing values. Shared game changes are limited to Soulblade motion, pose handoff, weapon launch and status rendering. Other fighters, accounts, seasons, lobby and backend remain intact. SoulMotion state and outgoing normal pose serialize through existing snapshots/rollback. Online simulation revision is 6360-soul41, rejecting older peers before Ready.

Validation: imported seven rig/source-mask/normal/W/transform/Q suites, native combat regressions, Mox integration regressions, DIRECT and WS fallback convergence with Soulblade movement/Q/W/E, and snapshot/restore. Existing Mox combo assertions in chain-cancel/status-combat were stale before this work (reproduced against the unmodified main-game HEAD): updated them for the approved full-R follow-up window, keeping damage and anti-infinite coverage. Browser smoke checked integrated Soulblade selection, mirror palettes and Sandbox rendering without game errors. Headless rendering measured roughly 2 ms idle / 6.2 ms Q at 1600x900 on this host; cloud-browser FPS varied substantially and is not a physical-device performance measurement. iPhone/iPad hardware performance remains unverified.
